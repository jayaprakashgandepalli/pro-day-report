## 1. Feature Verification Status Definitions

- **IMPLEMENTED AND VERIFIED:** Verified end-to-end across database models (`prisma/schema.prisma`), backend API routes (`src/app/api/**`), and interactive user interfaces (`src/app/**`).
- **PARTIALLY IMPLEMENTED:** Functional in the user interface and database models, but relies on client-side simulation for downstream actions or lacks deep background automation.
- **UI ONLY / BACKEND MISSING:** Visible frontend components or modals exist, but corresponding backend database persistence or API handlers are absent.
- **NOT IMPLEMENTED:** Capability is absent from the repository; either deliberately omitted (e.g., traditional classroom ERP features) or planned for future development.
- **UNABLE TO VERIFY:** Dynamic runtime verification could not be executed due to the absence of a live running database container or test harness in the audit environment.
